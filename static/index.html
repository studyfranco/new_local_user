Bienvenue sur Agent Hub

1. Choisissez l'agent Sélectionnez Codex ou Goose dans la barre latérale.
2. Connectez le flux Cliquez sur Connecter pour établir le pont WebSocket / Unix Socket via le serveur Rust.
3. Lancez vos instructions Créez un Thread/Session et interagissez en temps réel avec validation des outils.
